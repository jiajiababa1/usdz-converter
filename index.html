ZIP 模型一键转 USDZ

把装着 3D 模型的压缩包丢进来，自动解压、翻遍里面所有文件夹，把每个模型逐个转成 iPhone 能直接打开、用 AR 摆到桌上的 .usdz 文件。压缩包支持 ZIP / 7z / RAR / TAR，模型支持 OBJ / STL / GLB / glTF / FBX / DAE / PLY，带贴图的会把贴图一起打包进去。

使用说明

  • 转换结果：每个模型生成一个同名 .usdz，转好后点它右边的「下载」即可；也可以一键把全部结果打包成一个 ZIP 再下载。
  • 在 iPhone 上看：把 .usdz 存到「文件」App，点开就能看 3D，点右上角 AR 图标可以把它摆进房间里，双指捏合缩放。
  • 贴图要和模型放在一起：OBJ 的 .mtl 和贴图图片、glTF 的 .bin 和贴图，只要在同一个压缩包里（同文件夹或子文件夹都行），会自动配上。
  • 按名字自动配贴图：有些模型文件里根本没写贴图引用，这种就靠名字对上：贴图文件名里的部位词（自动去掉 Albedo、Texture 这类后缀和开头的角色名）会去对模型里的部件名，比如 Eye 对眼睛部件、Body 对身体、Jersey 对衣服；一个词对上多个部件会全都贴上。转完后每个模型下面会列出每张贴图贴到了哪个部件，没对上的也会明确写出来，不会悄悄丢掉。
  • 7z / RAR / TAR 也可以：和 ZIP 一样直接选就行，在手机本地用 7-Zip 引擎解压，第一次会多等几秒加载引擎；但设了密码的压缩包解不开，请先在别处去掉密码再压。
  • 动画和骨骼不会保留：USDZ 输出的是静态模型，FBX / glTF 里的骨骼动画转不了；模型本身的形状、材质颜色和贴图会保留。
  • 已经是 .usdz 的文件会原样列出来，可直接下载，不重复转换。
  • 文件太大时（单个模型超过约 20 万个面）手机浏览器可能转得慢或内存不足，建议先在 ZIP 里拆小，或换电脑浏览器打开本页转换。
